# Developing urcapgen

urcapgen turns one `urcap.toml` into a PolyScope 5 URCap (Java 8/Swing OSGi bundle) and a
PolyScope X URCap (plain-JS web components + workers, optional Docker backend), and
scaffolds a URCap monorepo with CI/CD and an assistant skill. Read `README.md` first. The
skill that ships to monorepos is `urcapgen/template/.claude/skills/urcap/`; read it to know
what users are told.

## Invariants

- **Stdlib only.** Python 3.11+ (`tomllib`). Java tools via `ps5.java_tool` (JDK on PATH /
  `URCAPGEN_JDK` / `JAVA_HOME` / Docker `eclipse-temurin:21-jdk`), Node for parity. Playwright
  only in `e2e.py`, imported lazily.
- **Three template engines, one language.** `scripttpl.py` is the spec;
  `runtime/ScriptTemplate.java` and `runtime/urcapgen-runtime.js` must render byte-identical
  output. `tests/test_scripttpl.py` fuzzes all three. Change all three together, or none.
- **Generated code compiles with `javac --release 8 -Xlint:all -Werror` against PolyScope
  5.4's API.** Nothing newer, no warnings. Generated JS runs on PolyScope X 10.8+ (no API
  that appeared later without a feature check).
- **Every generated file carries the `GENERATED by urcapgen` marker** in its first two lines
  (or is in `generate.ALWAYS_GENERATED`). User-owned files (hooks, daemon) are created once
  and never rewritten. `tests/test_generate.py` checks both.
- **Names are derived in `spec.py` only** (`Spec.psx_tag`, `ps5_file`, `Node.cls`, …).
- **Builds are reproducible** (fixed timestamps, sorted entries, normalised modes).
- **Never commit or redistribute UR's jars**, and never bundle UR's npm packages.
- Platform facts in comments and docs carry their source (SDK version, sample, or the
  simulator run that verified them). Mark unverified claims as unverified.

## Checks

```bash
python3 -m unittest discover -s tests -t .           # JDK tests use $URCAPGEN_JDK or Docker
URCAPGEN_TEST_SDK=<dir with 5.4/> python3 -m unittest discover -s tests -t .   # + PS5 parity
```

End to end, the way CI does it (`.github/workflows/ci.yml`):

```bash
python3 -m urcapgen init /tmp/m && cd /tmp/m
./urcapgen new demo --name Demo --vendor-id acme --vendor-name Acme --parts installation,program,toolbar,daemon
./urcapgen parity && ./urcapgen build
./urcapgen e2e-ps5 demo --version 5.4 && ./urcapgen e2e-psx demo --version 10.13
```

## Versioning

Bump `urcapgen/__init__.py` `__version__` for every change that alters generated output or
the template. Monorepos pick it up with `./urcapgen upgrade` + `./urcapgen gen`.

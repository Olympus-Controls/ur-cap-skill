# {{REPO_NAME}}: instructions for coding assistants

This repository holds Universal Robots URCaps. Each one is built for **PolyScope 5**
(e-Series, `.urcap`) and **PolyScope X** (`.urcapx`) from one spec, `urcaps/<id>/urcap.toml`,
with the vendored tool `./urcapgen` (urcapgen {{URCAPGEN_VERSION}}).

**Before changing anything under `urcaps/`, read `.claude/skills/urcap/SKILL.md`** and the
reference it points to for your task (`.claude/skills/urcap/references/*.md`). Those files
are plain markdown, written for any assistant.

The essentials:

- `urcap.toml` is the source. Files whose first line says `GENERATED by urcapgen` are
  rewritten by `./urcapgen gen`. Never edit them.
- Hooks (`*Hooks.java`, `*.hooks.js`) and `daemon/` are hand-written. The Java and JS hooks
  must write identical URScript; `./urcapgen parity` checks it.
- Before committing: `./urcapgen gen --check`, `./urcapgen parity`, `./urcapgen build`.
  If you couldn't run one, say so.
- Release = bump `version`, merge, tag `<id>-v<version>`.
- `tools/urcapgen/`, `.claude/skills/urcap/` and `.github/workflows/urcapgen-*.yml` are
  managed by `./urcapgen upgrade`. Don't edit them here.

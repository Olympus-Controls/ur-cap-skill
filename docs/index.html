For Universal Robots users

Describe a URCap. Claude builds it.

Tell Claude what the URCap should do, in your own words. You get a URCap for PolyScope 5 and PolyScope X, tested on every software version UR has released, ready for a USB stick.

Download the skill (urcap-skill.zip)

What you need

ClaudeA paid plan (Pro or higher), in the Claude app for Windows or at claude.ai
GitHubA free account at github.com. It builds and stores your URCaps
Robote-Series on PolyScope 5.4+, or PolyScope X 10.8+. Not CB3
USB stickAny normal stick (FAT32)

Nothing to install on your computer.

Set up once

  1. Download the skill

    Get urcap-skill.zip. Leave it zipped.

  2. Add it to Claude

    In Claude's Settings, make sure Code execution and file creation is on.

    Then Settings → Customize → Skills → Upload skill, and pick the zip.

  3. Make a place for your URCaps on GitHub

    On github.com click New repository, name it (for example my-urcaps), tick Add a README file, then Create repository.

  4. Open it in Claude

    In Claude, open Code. Connect your GitHub account when asked, and choose the repository you just made.

Ask for a URCap

In that Code session, say what you want, the way you'd explain it to a colleague. For example:

Make a URCap called Part Counter. Add a program node "Count Part" that adds one to a part counter and pops up a message every 100 parts. In the installation screen, let me set the popup interval and reset the count.

Make a URCap called Vacuum Gripper with two program nodes, Pick and Release. Pick turns on tool digital output 0 and waits for standard digital input 3 (vacuum OK). If it doesn't come on within a timeout I can set in the node, default 2 seconds, stop with a popup. Release turns output 0 off and pulses output 1 for 0.3 seconds.

Add a toolbar button to Part Counter that shows the current count.

Claude asks about anything it can't work out: your company name, which inputs and outputs, units and limits. It never guesses I/O numbers or motion values. Then it builds the URCap and saves it to GitHub.

Get it on the robot

  1. Wait for the green tick

    GitHub tests your URCap in Universal Robots' own simulator, on every PolyScope 5 version from 5.4 and every PolyScope X release. It takes 20–40 minutes. Watch it on your repository's Actions tab. ✓ green means it worked everywhere. If anything fails, tell Claude "the tests failed, fix it".

  2. Say "Release it"

    A minute later the files are on your repository's Releases page. Download them and copy them to the USB stick.

  3. Install on the pendant

    PolyScope 5 (e-Series)

    1. Plug in the stick with the .urcap file
    2. ☰ → Settings → System → URCaps → +
    3. Pick the file → Restart

    Shortcut: also copy the urmagic_…sh file to the stick and turn on Settings → Security → General → Run magic files. The robot then installs it by itself when the stick goes in (arm powered off).

    PolyScope X

    1. Plug in the stick with the .urcapx file
    2. ☰ → System Manager → URCaps
    3. Add the file
Before production: the simulator tests catch a broken URCap, not an unsafe program. Run every new URCap on the real robot at reduced speed first, like any new program.

Questions

How do I change a URCap later?

Open the same repository in Claude's Code tab and say what to change: "make the default timeout 3 seconds", "add a node that…". Wait for the green tick, then say "Release it" again.

Can my repository be private?

Yes. GitHub gives free accounts 2,000 test minutes a month on private repositories, and a full test run uses a good part of that. Public repositories test for free without limit.

Can I do this without GitHub?

Claude can design a URCap in a normal chat and give you the source as a zip, but it can't build or test the robot files there. GitHub does that part.

Which robots does it work on?

Any UR arm running PolyScope 5.4 or newer (e-Series: UR3e, UR5e, UR10e, UR16e, UR20, UR30 and others) or PolyScope X. CB3 robots (PolyScope 3) are not supported. A URCap with a toolbar button needs PolyScope X 10.10 or newer.

Who owns the URCaps I make?

You do. The skill is free and open source (MIT licence).
